# Portal de séries e filmes de Halloween

## Este é um pequeno portal sobre filmes e séries de Halloween que serve para organizar o versionamento. 

## Navegação entre as páginas disponíveis.
## Formulários para entrada e consulta de informações.
## Exibição e organização dos dados relevantes.
## Interface responsiva e de fácil utilização.
## Implementação de funcionalidades adicionais conforme os requisitos do projeto.

## Tecnologias utilizadas: HTML, JavaScript, Git e GitHub. Para visualizar o portal, é necessário um computador com navegador atualizado. O Visual Studio Code pode ser utilizado para editar e executar o projeto localmente.

## Fluxo de branches: o projeto utilizará a main como branch estável e a develop como branch de integração, além de seis branches de trabalho:

## feature/series
## feature/cadastro
## fix/correcao
